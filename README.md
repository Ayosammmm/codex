# Almanach

Almanach est une app blabla

## Installation
- Dans "backend", créez un fichier .env avec les champs du .env.example, puis complétez les à votre convenance. Le but est de connecter l'application à une base de données, et de créer un premier compte super admin.

- Installez les dépendances.

```
cd backend
npm i
cd ../frontend
npm i
```

- Lancez le backend et le frontend (le frontend soit en mode de developpement, soit vous le construisez et publiez le site en faisant en sorte que la racine d'entrée soit frontend)

```
cd backend
npm run start
```

```
cd frontend
npm run dev
```
